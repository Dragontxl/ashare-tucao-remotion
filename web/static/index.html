GitHub Actions 云端运行

          
在 GitHub 上运行完整流水线，产物自动上传到 Cloudflare R2。需要填入 GitHub PAT（需 repo, workflow 权限）。

          
云端模式下，GitHub 与 R2 配置由 Cloudflare Secrets 管理（wrangler secret put / wrangler vars），此处仅展示状态，不可修改。
